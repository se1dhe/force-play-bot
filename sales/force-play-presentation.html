Что получает сервер

Бот закрывает путь от привязки аккаунта до удержания игроков.

Привязка аккаунта L2

Выбор сервера, ввод ника, подтверждение в игре через game server API. Список аккаунтов и персонажей в боте.

Безопасность

HWID: отвязка персонажа, approve/deny нового входа с TTL. Trade Key: смена пароля торговли с валидацией.

Автофарм

Статус фарма, уведомление о смерти, викторина для revive и перезапуска. Webhook смерти с game server.

Уведомления

Респавн боссов, старт ивентов, рестарт сервера, автофарм — убили. Маска настроек на пользователя.

Бонусы и промо

Бонус за подписку на канал, промокод дня по cron, выдача предметов на GS. Реферальная программа со счётчиком.

Колода Lineage 2

Mini App: расклад 3 карт, pity, коллекция, трофеи, лента ROYAL, покупки Telegram Stars, сезоны и админ-CRUD.

Интеграция с game server

Бот и L2J говорят на одном языке API.

Привязка аккаунта, профиль персонажа, бонусы, промо, автофарм и внутренние webhook'и — по спецификации из servers.yml и endpoins.md.

Привязка

link/request → confirm в игре → webhook в бот.

Персонажи

Профиль: уровень, класс, PvP/PK, клан, online.

Анонсы

BOSS_SPAWN, EVENT_REGISTRATION, SERVER_RESTART.

Режимы

mock / real integration, demo-data для стенда.

Спринты продукта

Эволюция от MVP-бота до Mini App «Колода».

Ниже — этапы разработки по миграциям и экранам webapp. Три вкладки Mini App — отдельный спринт UX после ядра бота.

01 · V1–V2

Каркас и GS

PostgreSQL, Flyway, привязка аккаунта, выравнивание с game server API.

02 · V3–V4

HWID и безопасность

Запросы на уровне персонажа, слоты HWID, approve/deny, Trade Key.

03 · V5–V9

UX и удержание

Уведомления, выбор языка, бонус за канал, промокод дня, рефералы.

04 · V10–V12

Tarot of Destiny

Сезоны, арканы, расклады, Stars, лента ROYAL, лор и имена в ленте.

WebApp · вкладки

Печать → Трофеи → Лента

Печать: start → reveal по карте → claim, pity, пакеты Stars. Трофеи: фильтры COMMON / RARE / ROYAL. Лента: глобальные эпические открытия + уведомление в боте.

Внедрение

Запуск под ваш сервер без долгих согласований.

Настраиваем бота, endpoints на L2J, Mini App URL и админов. Проверяем сценарии привязки, HWID и тестовый расклад в «Колоде».

01

Конфигурация

BOT_TOKEN, ADMIN_IDS, servers.yml, messages.yml, Redis, PostgreSQL, TAROT_WEBAPP_URL.

02

Game server API

Реализация endpoint'ов по endpoins.md: link, profile, bonus, promo, autofarm, announcements.

03

Telegram и Mini App

Кнопка Web App в меню, HTTPS на /tarot/, проверка initData, Stars payments.

04

Проверяем сценарии

Привязка, HWID approve, промо cron, уведомление босса, расклад ROYAL и рассылка админа.
